# BalkanBlick

Beispielseite fuer Balkan-TV in der Schweiz.

Webseite: https://brankofilev.github.io/balkanblick/

## Funktionen
Drei Beispielpakete, Monats-/Jahrespreise, Geraeteauswahl und lokale Demo-Anfrage.

## Lokal oeffnen
index.html im Browser oeffnen. Keine Installation erforderlich.

## Status
Designvorschau: keine TV-Zugaenge, Zahlungen oder Bestellungen. Beispielpreise sind unverbindlich. Formularangaben werden nicht versendet. Noch keine Partnerschaft mit den verlinkten TV-Anbietern.

## Veroeffentlichung
GitHub Pages verwendet den Branch main und das Stammverzeichnis. Aenderungen an index.html werden automatisch veroeffentlicht.
